# Kenya Admissions Portal

Web design and development

CAT II

Question 1 (20 Marks)

A Kenyan university wants a prototype online admission portal.

Develop a mini web application using HTML, CSS, and JavaScript that includes:

Part A: User Interface (8 Marks)

 University banner

 Navigation menu

 Admission application form

 Footer section

Part B: Form Validation (6 Marks)

Implement JavaScript validation for:

 Name field

 Email field

 Phone number field

 KCSE Index Number field

Part C: Dynamic Processing (6 Marks)

The system should:

 Validate all inputs.

 Display a success message upon submission.

 Generate a unique application reference number automatically.

Additional Requirement

Provide a brief evaluation explaining:

 Website layout decisions.

 Validation techniques used.

 How the solution improves efficiency compared to manual admissions.
